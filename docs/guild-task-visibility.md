# 繰り返しタスクの表示開始

Supabase SQL Editorで `supabase/migrations/0128_sakaba_task_visibility.sql` を実行する（0125適用済みが前提）。
DB更新前でも通常のタスク追加・編集・完了は従来のRPCで動作する。表示開始の設定欄は更新後に出る。

プロジェクトのタスクの鉛筆から、くり返しを指定し、「いつから表示する？」で常に表示／当日／3日前／7日前／日数を指定（0〜365）を選び保存する。
既存タスクの初期値は常に表示。設定前に隠れるタスクはない。
表示前は「今後の予定」にまとめ、そこからも編集・完了できる。ホームの期限が近い一覧も同じ条件で隠す。
設定は次回作成時に引き継ぐ。期限超過の未完了は常に残す。工程表・完了数・通知の配信時刻は従来どおり。

適用後の実操作確認：毎月28日・3日前で保存し、25日より前には「今後の予定」に移ること、常に表示へ戻すと通常一覧に戻ることを確認する。
完了で作られた次回にも設定が残ること、完了を取り消しても次回が二重にできないことを確認する。
